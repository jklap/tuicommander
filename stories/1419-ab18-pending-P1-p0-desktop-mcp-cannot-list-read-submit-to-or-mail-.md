# [P0] Desktop MCP cannot list, read, submit to or mail sessions on a connected remote daemon

## Problem Statement

From the Mac desktop MCP, repo list shows the remote repo of connection Mac-mint (Direct http://mac-mint:9877, tuic-remote 1.7.7 Linux), but session list and agent list_peers omit its PTYs, and agent send to a remote tuic_session returns not registered. docs/user-guide/remote-access.md promises remote sessions listed beside local ones with a connection tag and calls routed to the owning machine. An orchestrator on the Mac cannot reach an agent on a remote at all; the only workaround was SSH plus a hand-driven tuic-bridge, which Boss rejects. Evidence: ~/Gits/.tmp/coordinator/urgent-remote-incident.md (br-2, 2026-10-03).
